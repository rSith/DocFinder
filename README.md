# DocFinder Health System v1.0

## 🩺 Project Overview
DocFinder is a JavaFX-based desktop application that helps users identify diseases based on symptoms and find relevant specialists. It features a secure login, a dynamic symptom checker, and a doctor directory with real-time filtering.

## 🚀 How to Run
1. **Prerequisites:** Java JDK 21, Maven, MySQL.
2. **Database Setup:** - Import the `docfinder_db.sql` file (included in `resources/`) into your MySQL server.
   - Update `src/main/resources/db.properties` with your database credentials.
3. **Build & Run:**
   - Open terminal in project root.
   - Run: `mvn clean install`
   - Run: `mvn javafx:run` (or run `AppLauncher.java` in IntelliJ).
